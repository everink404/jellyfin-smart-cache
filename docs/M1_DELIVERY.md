# M1：0.4.0.0 生命周期接入测试版

日期：2026-10-16（Asia/Shanghai）。本批完成实际生命周期接入与可安装成品，线上分发核验结果见STATUS。插件身份仍为JellyCache single-plugin read test，GUID保持不变。

## 安装与回退

插件库地址不变：

```text
https://everink404.github.io/jellyfin-smart-cache/manifest.json
```

在插件目录刷新并选择0.4.0.0，停止播放后升级，重启Jellyfin。保留已有配置和受管目录，不删除缓存，不重复安装手工DLL副本。新安装默认关闭；升级保留原启用／自动模式设置。目标Jellyfin12.1.0／.NET10，其他版本未验证。

安装后查看插件配置：自动模式状态应为已就绪，并显示“按请求和任务结束释放”。若显示保守保护，说明服务注册不符合已验证的官方结构，不能据此认定生命周期接入已启用；保留状态与日志供诊断。

如需回退：停止播放，使用Jellyfin插件管理卸载0.4.0，再从同一目录安装保留的0.3.1.0并重启；保留插件配置和受管缓存目录。只处理该插件版本，不清理/video、其他插件或Jellyfin数据库。0.3.1恢复保护至重启的行为。UI若不提供降级入口，先停止在这一步并反馈，不手工删除用途不明的目录。

## 本版完成了什么

- 仅预协商返回原来源描述，不长期保护未播放候选；实际取流再解析有效缓存。
- 直接文件响应在请求作用域持有保护，正常结束、断开或异常展开时归还。
- 官方ITranscodeManager在实际启动ffmpeg前增加独立保护，确认进程结束后归还；HTTP分片结束不提前释放仍运行作业。
- 官方ISubtitleEncoder和IAttachmentExtractor覆盖独立提取任务。异常或取消导致无法确认原生读取结束时，去重转为保守保护，不凭超时猜测安全。
- 复用仍活跃的缓存作业时取得请求过渡保护；已退出作业中的缓存路径不直接复用，重新解析来源，支持回收后再次请求。
- 复制结果区分取消、容量／保护限制和明确失败类别；状态页显示最近结果、失败次数、耗时及读取保护引用。

只对已识别的官方12.1单例注册安装全部编码包装与中间件，未知注册保持保守模式。自动模式之外的原手动读取模式继续保留。原条目ID、媒体源ID、库路径、续播和历史入口不变；没有独立Worker或媒体库路径迁移。
