# 单插件自动预取测试 0.3.0.0

本版沿用 JellyCache single-plugin read test 的 GUID，升级后配置页增加自动预取模式。0.2.0.0 手动读取模式继续保留，旧包和检查点保留。目标 Jellyfin 12.1.0 / .NET 10。

## 安装与配置

插件仓库地址保持 `https://everink404.github.io/jellyfin-smart-cache/manifest.json`。只有目录显示 **0.3.0.0** 并安装重启后，才能测试本页的自动预取功能；发布进度以 STATUS 为准。若仍显示 0.2.0.0，刷新仓库和目录，不必重新建立仓库。

2026-10-13 已发布并匿名下载校验：[0.3.0.0 ZIP](https://everink404.github.io/jellyfin-smart-cache/packages/v0.3.0-prefetch-test.1/JellyCache.ReadProbe_0.3.0.0.zip)。SHA-256：`ca727e70a2dfeadc37c24ce578bc20e1476283a8080d00c0fa662117d2cb7c6f`。自动模式真实容器功能仍待验收。

1. 停止播放，升级已有 JellyCache single-plugin read test，重启 Jellyfin。不要同时安装旧目录下 DLL 的手工副本。
2. 打开插件配置，勾选“启用插件”和“自动预取模式”。新安装默认关闭，升级保留原手动配置；不会自动切到预取模式。
3. 媒体根目录填写容器内 `/video`，或实际剧集根目录。缓存目录填写容器内专用空目录，例如 `/excache/jellycache-managed`。原手动副本所在 `/excache` 非空，不能直接作为新受管根目录；必须用新的专用子目录。它须位于本地磁盘且可写，并与媒体根目录分开。插件不创建 Docker 挂载。
4. 设置容量、磁盘保留余量和预取速率。默认 10 GiB／2 GiB／8 MiB/s；根据测试磁盘可用空间调整。选择“后续 N 集”，N=2。
5. 保存，刷新状态，等待“已就绪”。若目录或权限错误，检查后重新保存可重试。首次存储打开后改变目录、容量、余量或速率需要重启；策略、N、暂停和启用开关可以动态调整。

## 第一轮：自动预取与命中

选同季至少三集、单版本、普通 Episode 的小范围测试。首次启用或重新启用后，停止旧播放再新播放，以产生开始事件。

1. 播放 E01；刷新插件状态应显示 E02、E03，E02 优先复制。队列按 Jellyfin 已识别的集序计算，不按文件名猜测。
2. 等待 E02 显示“缓存就绪”。未完成、复制失败或空间不足时仍用原来源，新播放不会等待复制完成。
3. 从原媒体条目播放 E02；确认画面、声音、进度、续播和前后拖动正常。日志应出现 `JellyCache prefetch selection: cache; stage=stream-resolution`。
4. 若实际转码／重封装，ffmpeg 输入应是专用目录中的 `.media` 文件；媒体库仍显示原条目。纯直放需结合取流与文件 I/O 证据，不能只看协商日志。
5. 窗口推进为 E03、E04。跳集后窗口随之调整；重复进度事件不会重复复制已完成项。到季末停止扩展，特殊集、合并集、多版本或不明确元数据保持原来源。

## 第二轮：暂停、空间与恢复

- 勾选暂停预取并保存：在途复制取消并清理临时文件，新复制暂停，已完成缓存仍可播放。取消暂停后按当前窗口继续。
- 停止播放：移除该会话待预取需求；其他仍活跃会话需求保留。15 分钟无事件的会话失效。
- 用较小预算测试空间不足：正在使用和当前窗口中的缓存优先保留，无法腾出空间时显示等待，不反复淘汰 E02／E03来回复制，也不删除原文件。
- 关闭插件、停止播放后重播：回到原来源。复制失败最多尝试三次并退避；需要重新播放产生新需求才能重新开始一轮重试。
- 停止播放并重启容器：重新校验完整缓存，清理有记录的未完成复制；重新播放恢复需求。重启不恢复旧播放会话的预取窗口。

不要修改正在播放的缓存。缺失／损坏测试在停止播放后进行，且保持原来源完好。未知目录文件会使后续存储打开失败并保留文件，不会被随意清除。

## 本轮边界

**被选中过的缓存从协商／取流开始保护到 Jellyfin 关闭，重启后解除。** 这是保守保护，避免无法可靠判断 ffmpeg 与客户端结束时提前淘汰；没有承诺播放结束即回收。保护项会逐渐占用容量，满后停止新增预取，不突破预算。状态页显示保护项数量。

目前未提供手工清空按钮，也不自动判断当前播放卡顿或动态抢占挂载带宽；以可配置限速和暂停保障资源。命中时仍要确认原来源版本，不支持来源完全离线。外置字幕仍依赖原路径。

检查证据：167 项 C# 检查（规划36、存储44、执行器／事件28、读取回归37、宿主22）及配置页模拟 DOM/API 检查通过。宿主夹具使用真实固定官方媒体源管理器、实际季集查询方法、播放事件及合成小文件；没有运行完整 Jellyfin 服务、真实浏览器或 ffmpeg。Docker 沙盒尚不可用，本版自动预取仍需真实容器验收。

验收时提供：插件版本、操作时间、状态页队列、实际播放模式，以及该时间段 `JellyCache prefetch` 与 ffmpeg 输入日志。用户画面声音确认、日志检查和本机自检分开记录。
