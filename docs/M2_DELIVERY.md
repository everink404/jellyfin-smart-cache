# M2：安全管理测试版0.4.1.0

日期：2026-10-16（Asia/Shanghai）。这是M2功能补齐成品，完整M2矩阵仍在验收，不宣称全部通过。原插件名、GUID、配置与分发入口保持不变。

## 安装与使用

从原插件库升级JellyCache single-plugin read test至0.4.1.0，停止播放后重启Jellyfin。仓库地址仍为：

```text
https://everink404.github.io/jellyfin-smart-cache/manifest.json
```

新安装默认关闭，升级保留已有启用、自动模式、目录及资源参数。0.4.0.0、0.3.1.0及0.2.0.0旧包保留，不覆盖。

配置页新增“清理未占用缓存”：

1. 勾选“暂停预取”并保存，刷新到已暂停；等待在途复制取消并归还预留。
2. 点击清理，确认后仅删除索引内未占用的完整缓存；当前请求、ffmpeg、字幕／附件及保守保护项均跳过。原媒体和未知文件不会被删除。
3. 查看删除项数、字节及跳过占用项数。复制尚未结束时返回忙碌，稍后重试；目录有未知文件时拒绝清理并保留，不递归删除。
4. 播放结束后可再次清理之前跳过的缓存，无需重启。恢复预取后，当前窗口可能重新下载。

页面勾选尚未保存并不算服务已暂停，服务端会再次验证。接口要求管理员且只接受POST；不会自动运行清理或修改暂停设置。目录／容量等结构配置改变后，仍须停止播放再重启。

回退：停止播放，在Jellyfin插件管理卸载0.4.1并从原库安装0.4.0，再重启；保留配置及受管目录。清理已删除的缓存不由回退恢复，但原文件仍在，后续可以重新预取。UI没有降级入口时反馈，不手工清理用途不明目录。
